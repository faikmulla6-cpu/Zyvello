Help

What Zyvello is, how it works, and how to fix the usual problems.

What is Zyvello?

Zyvello is an autonomous AI sales agent. Once set up, Zyvello runs on its own: finds people who match your ideal customer, writes personalized cold emails, sends them through your email platform, reads every reply, handles objections, and works toward booking a meeting. You review everything through this dashboard.

Zyvello runs on your Claude Max subscription (or, if you opt in, your ChatGPT plan through Codex), so there are no extra AI costs. Everything stays on your machine in one folder.

Getting started

There are three things to do:

1. Go to the Settings tab and connect an email provider (Gmail recommended)
2. Train Zyvello on your product (through Claude or the command line)
3. Go to the Controls tab and click Start

Getting your API keys

Instantly API key (legacy)

Instantly is the legacy sending option; Gmail or SMTP is recommended.

1. Sign up at instantly.ai (you need the Growth plan for API access)

2. Go to Settings > Integrations

3. Copy your API key

4. Paste it in the Settings tab here

LinkedIn credentials (optional)

If you want Zyvello to find prospects on LinkedIn, enter your LinkedIn email and password. Zyvello uses a real browser to search LinkedIn like a human would, with random delays and rate limits to avoid detection.

If you skip this, Zyvello will find prospects through Google searches and company website scraping instead.

Cloudflare Browser Rendering (optional)

This is only used during product training (when Zyvello crawls your website to learn about your product). It handles JavaScript-heavy websites that a basic crawler can't read.

1. Sign up at Cloudflare (paid Workers plan, ~$5/month)

2. Go to Workers & Pages > Browser Rendering

3. Create an API token with Browser Rendering Edit permissions

4. Enter your Account ID and API Token in the Settings tab

Without this, Zyvello uses a built-in crawler that works fine for most websites but can't render JavaScript.

Common issues

"local command not found"
You need to activate the virtual environment first: source .venv/bin/activate
Instantly API returns 401
Your API key is wrong, or you need the Growth plan (the free plan doesn't include API access). Double-check the key in Settings > Integrations in your Instantly dashboard.
Claude headless mode fails
Make sure you've run claude login in your terminal and have an active Claude Max subscription. Zyvello uses your existing subscription, not a separate API key.
Codex calls fail
With brain.provider: codex, set brain.model to an available model ID, including Luna, Sol, or Terra (for example gpt-6.1-sol), or leave it blank to select a listed model. Zyvello runs these models without tools; gpt-5.5 also remains supported when present in your account's catalog. Run codex login and choose "Sign in with ChatGPT" (API-key logins are refused). Zyvello never renews your Codex login: if the log says it has expired or is due for renewal, use Codex once or run codex login. Zyvello needs Codex CLI 0.159.3 on macOS or Linux (Codex isn't supported on Windows; use Claude there) and refuses other versions. While Codex can't be used, Zyvello pauses (Today shows "Codex is paused" and why), leaves replies and queued emails untouched, and resumes once it's fixed; the local status check checks on demand. If the log says isolation could not be verified, a Codex config layer is forcing a tool, hook, MCP server or custom endpoint back on — Zyvello refuses to send prompts until it is removed. Zyvello never falls back to Claude on its own.
Zyvello isn't finding prospects
Check that your ICP (ideal customer profile) in local configuration file has realistic titles, industries, and geography. If LinkedIn is set up, check that the credentials are correct. Check the Activity tab to see what Zyvello has been trying to do.
