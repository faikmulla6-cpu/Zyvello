AI provider

Groq uses your own API key. Claude and Codex remain available. Save, then restart automation to apply provider or model changes.

Create a key at Groq Console. Select a primary key and add backups with +. Keys stay masked after saving.

If a key is rejected, temporarily fails, or reaches a rate limit, try eligible backups in key-number order. Limited keys respect Groq’s retry delay; other failures wait one minute. If all keys are unavailable, automation waits. Keys in one Groq organization can share limits.

Gmail / Google Workspace Recommended

Use a mailbox on a dedicated secondary domain. Create an OAuth client (type "Desktop app") in Google Cloud Console → Gmail API, paste the id and secret, save, then complete Gmail authorization through Mailbox connections above.

SMTP + IMAP mailbox

Any real mailbox (AgentMail, Fastmail, a Workspace app password). IMAP defaults to the SMTP host and login if left blank.

Reading replies from a different IMAP server or login

Microsoft 365 / Outlook

Microsoft turned off password sign-in for IMAP, so Outlook mailboxes connect with OAuth. In Entra → App registrations, register an app for your organization only and add the redirect URI http://localhost:8766 as "Public client/native". Paste both IDs here, save, then complete Microsoft authorization through Mailbox connections above. No client secret is needed.
